# Translation Manager Docs

Translation Manager provides a file-based Filament editor for Laravel language files with side-by-side locale editing, missing and stale key checks, reviewed AI drafting when configured, and safe package override writes.

Start at the [package README](../README.md) when deciding whether to install this package. Use the docs below for setup, extension, debugging, and verification details.
